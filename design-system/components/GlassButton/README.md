Class prefix `.c-glass-button`. Styles ship in `components/bundle.css`; load `c-glass-button.css` alone only outside this system. No script.

A secondary text action using the existing `rm-btn--glass` material, composed with `rm-btn` geometry and `t-body-strong`. Unlike the icon-only glass atom, this retains the standard text button height and padding. No new tokens or changes to existing atoms.

```html
<button class="rm-btn c-glass-button t-body-strong">Sign in</button>
```

Use behind a readable, restrained background. Existing focus, press, hit area and disabled behavior come from `rm-btn`. User requested for MEL welcome on 2026-10-09. Source verified; visual approval pending.
