# Mel skill pill

Name pill for a Mel skill, next to its mark (brand 10 Assistants). Class `.c-mel-skill-pill` with `data-skill`. No script.

```html
<span class="c-mel-skill-pill" data-skill="crm">CRM Assistant</span>
```

- **Skills.** `marketing` Coral, `crm` Lagoon, `campaign` Honey, `client` Rose, `compliance` Harbor, `document` Cocoa. No `data-skill` = Mel (Mel tint, green text).
- **Colours.** Light values are the brand values. Dark values are derived (accent at 18% over `surface-card`, text lightened to pass 4.5:1). Tokens `mel-skill-<k>-pill`, `mel-skill-<k>-pill-fg`.
- **Rules.** Accent only for its own skill: its mark, its pill, small highlights on its pages. Never body text, buttons or backgrounds. Never two skill colours in one place.
- **Names.** Use the brand names. MLS has no brand colour yet; show it with the plain Mel pill.
